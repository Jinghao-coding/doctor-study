Agent 使用说明

  • 内容源：所有可持续更新的学习内容放在 content/，按 domain/topic/*.md 拆成小文件。
  • 资料资源：论文、图片、简历附件、原始资料等放在 resources/；隐私材料放 resources/private/，不会提交。
  • 生成页面：运行 uv run python tools/build_site.py，自动生成 pages/domain/topic/index.html。
  • 新增主题：新增 content/domain/topic/topic.json 和章节 Markdown，再把主题注册到 content/site.json。
  • 导航目录：长页面右下角提供可隐藏目录按钮；按 Alt + E 展开 / 折叠当前页所有问答。
